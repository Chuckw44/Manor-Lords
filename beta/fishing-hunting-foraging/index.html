Review Build — Assumptions to Check
Fishing: reserve optimization uses the configured spring spawn dates and spawn-growth rate in the GAME settings block. Spring staffing uses the configured catch-per-spot rate, uptime, fishing-spot count, and people-per-family values. The current catch-per-spot rate is derived from observed results of roughly 146 fish/month from 11 spots and 80 fish/month from 6 spots.

Hunting: reserve = capacity − 2. Teeming changes rabbit spawning only: each spawn is +1 rabbit with a Woodland-% chance for one extra rabbit. Recommended camps are estimated from sustainable rabbit regeneration versus an editable per-camp hunting-throughput assumption. Active hunting produces equal Small Game and Pelts before Origin bonuses. Trapping is added separately as Small Game only, using the editable assumed trap count and 90-day cycle.

Foraging: season length, growth interval, growth fraction, Teeming bonus, and Vogtland capacity multiplier are all controlled from the GAME settings block.
